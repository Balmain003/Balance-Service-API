# Balance Service API

Микросервис для работы с балансом пользователей, обеспечивающий операции с финансами, резервированием средств и генерацией отчетов.

## Основные возможности

- **Управление пользователями**: создание пользователей и управление их балансом
- **Операции с балансом**: пополнение, переводы между пользователями
- **Резервирование средств**: бронирование средств для оплаты услуг с подтверждением или отменой
- **История транзакций**: полная история операций с пагинацией и сортировкой
- **Финансовая отчетность**: генерация месячных отчетов в формате CSV

## Технологический стек

- **Язык**: Go 1.24.4
- **База данных**: PostgreSQL
- **ORM**: GORM
- **Документация**: Swagger/OpenAPI
- **Валидация**: go-playground/validator
- **Конфигурация**: Environment variables

## Установка и запуск

### Предварительные требования

- Go 1.24.4 или выше
- PostgreSQL
- Установленные зависимости Go

### Настройка окружения

1. Клонируйте репозиторий
2. Создайте файл `.env` в корне проекта:
```env
DSN=host=localhost user=your_user password=your_password dbname=balance_db port=5432 sslmode=disable
```

3. Установите зависимости:
```bash
go mod tidy
```

### Запуск приложения

```bash
go run main.go
```

Сервис будет доступен по адресу: `http://localhost:8081`

## API Endpoints

### Пользователи и баланс

- `POST /user` - Создание пользователя
- `PATCH /balance` - Пополнение баланса
- `GET /balance/{user_id}` - Получение баланса пользователя
- `POST /transfer` - Перевод средств между пользователями

### Резервирование средств

- `POST /reserve` - Резервирование средств для оплаты
- `PATCH /reserve/confirm/{reservation_id}` - Подтверждение резервирования
- `PATCH /reserve/cancel/{reservation_id}` - Отмена резервирования

### История и отчеты

- `GET /history` - История транзакций пользователя
- `GET /report` - Генерация месячного отчета
- `GET /download/{filename}` - Скачивание отчета

## Документация API

После запуска приложения документация доступна по адресам:

- Swagger UI: `http://localhost:8081/swagger/index.html`
- Swagger JSON: `http://localhost:8081/swagger/doc.json`

## Примеры использования

### Пополнение баланса

```bash
curl -X PATCH "http://localhost:8081/balance" \
  -H "Content-Type: application/json" \
  -d '{"user_id": 1, "amount": 1000}'
```

### Резервирование средств

```bash
curl -X POST "http://localhost:8081/reserve" \
  -H "Content-Type: application/json" \
  -d '{"user_id": 1, "service_id": 1, "order_id": 1, "amount": 150}'
```

### Получение истории транзакций

```bash
curl "http://localhost:8081/history?user_id=1&page=1&page_size=10&sort_by=date&sort_order=desc"
```

### Генерация отчета

```bash
curl "http://localhost:8081/report?year=2024&month=10"
```

## База данных

Приложение автоматически создает необходимые таблицы при первом запуске через GORM AutoMigrate.

Основные сущности:
- **users** - Пользователи и их баланс
- **reservations** - Резервирования средств
- **transactions** - История всех финансовых операций
- **report_files** - Сгенерированные отчеты
